Опрос железа Windows

Отдельный проход по известным Windows-машинам. Процессор, ОЗУ, диски и версия ОС приходят из lookup bAD, когда связь в состоянии «Подключено». Учётка из Опроса сети нужна только чтобы увидеть службу badagent и MachineGuid. Пока bAD не подключён, старый опрос железа по WMI не запускается. По умолчанию — ежедневно в полдень.
