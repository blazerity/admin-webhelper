Учётка PsExec

Глобальная учётка для чтения серийника, MAC и текущей УЗ по WMI после ping. Пароль хранится только как шифротекст Fernet (ключ — FERNET_KEY). Если поля пустые и в .env нет DISCOVERY_*, WMI не вызывается: машина склеивается по hostname, MAC — из ARP в том же L2.

Обновление из git

Новая версия скачивается из публичного репозитория. Перед заменой кода всегда создаётся копия для отката. После замены службы перезапускаются от sudo-учётки ниже.

Linux-учётка с правом перезапускать службы (обычно root). Пароль шифруется Fernet (ключ — FERNET_KEY) и при обновлении передаётся в su — отдельный sudoers не нужен. Без пароля остаётся вариант sudo -n и файл deploy/bawh-update.sudoers. Пустой логин очищает учётку.
