Учётка PsExec

Глобальная учётка для чтения серийника, имени машины, MAC и текущей УЗ по WMI после ping. Имя на карте — с самой машины (Win32_ComputerSystem); PTR только запасной и не участвует в слиянии. Идентичность устройства — только серийник: смена IP при том же SN обновляет ту же карточку. Если поля пустые и в .env нет DISCOVERY_*, WMI не вызывается: без SN остаётся заглушка по текущему IP, MAC — из ARP в том же L2. Пароль хранится только как шифротекст Fernet (ключ — FERNET_KEY).

Опрос железа Windows

Отдельный проход по уже известным Windows-машинам (не ICMP-опрос сети): ping, затем WMI — процессор, вся ОЗУ, суммарный объём дисков, версия Windows (10/11/Server, Pro/Enterprise, 25H2/26H2). Учётка та же, что для серийника. По умолчанию — каждый день в полдень по часовому поясу сервера.

Управление службами

Linux-учётка для systemctl: запуск bawh-scheduler при включении тумблеров отчётов и перезапуск служб после обновления из git.

Обычно root. Пароль шифруется Fernet (FERNET_KEY) и передаётся в su — отдельный sudoers не нужен. Без пароля — sudo -n и deploy/bawh-update.sudoers (restart / start / enable scheduler). Пустой логин очищает учётку.

Обновление из git скачать релиз, откат, страница обновлений

Новая версия скачивается из публичного репозитория. Перед заменой кода всегда создаётся копия для отката. После замены службы перезапускаются от учётки выше («Управление службами»).
