Почта (SMTP)

Общая рассылка для модулей «Пароли AD» и «Отчёт по секторам». Если поля пусты — берутся SMTP_* из .env. Пароль хранится зашифрованным.

{% set smtp_cfg = smtp if smtp is defined else none %}

Пароль шифруется перед записью в базу. Ключ шифрования — FERNET_KEY в окружении, не в этой форме. Учётка ниже только ваша: у другого администратора свои поля. Если пользователь и пароль пустые, PsExec запускается от имени вашего входа на сайт.

Учётка PsExec

Глобальная учётка для чтения серийника, имени машины, MAC и текущей УЗ по WMI после ping. Имя на карте — с самой машины (Win32_ComputerSystem); PTR только запасной и не участвует в слиянии. Идентичность устройства — только серийник: смена IP при том же SN обновляет ту же карточку. Если поля пустые и в .env нет DISCOVERY_*, WMI не вызывается: без SN остаётся заглушка по текущему IP, MAC — из ARP в том же L2. Пароль хранится только как шифротекст Fernet (ключ — FERNET_KEY).

Опрос железа Windows

Отдельный проход по уже известным Windows-машинам (не ICMP-опрос сети): ping, затем WMI — процессор, вся ОЗУ, суммарный объём дисков, версия Windows (10/11/Server, Pro/Enterprise, 25H2/26H2). Учётка та же, что для серийника. По умолчанию — каждый день в полдень по часовому поясу сервера.

{% set hw = hardware_poll_settings if hardware_poll_settings is defined else none %}
По умолчанию 0 12 * * * (12:00 локального времени).

CLI: flask --app wsgi hardware-poll --dry-run. На карточке устройства админ может опросить одну машину.

VNC в браузере

Лёгкий шлюз bawh-vnc (WebSocket на 127.0.0.1:6080) и noVNC на карточке устройства. На Windows — TightVNC или UltraVNC, порт обычно 5900, файрвол только с IP этого сервера. Тихая установка: библиотека Скрипты → «TightVNC (тихая установка)». MSI кладите в vnc-agents/ на этом сервере (обычно /opt/bawh/vnc-agents/), имя с 64bit или 32bit. Пароль TightVNC — не больше 8 символов.

Управление службами

Linux-учётка для systemctl: запуск служб отчётов (bawh-password-reports, bawh-pc-reports) и VNC-шлюза при тумблерах, перезапуск после обновления из git, применение HTTPS-сертификата.

Обычно root. Пароль шифруется Fernet (FERNET_KEY) и передаётся в su — отдельный sudoers не нужен. Без пароля — sudo -n и deploy/bawh-update.sudoers (restart всех служб / start / enable / stop scheduler, отчётов и VNC / sync-systemd-units.sh / apply-nginx-tls.sh). Пустой логин очищает учётку.

Обновление из git скачать релиз, откат, страница обновлений

Новая версия скачивается из публичного репозитория. Перед заменой кода всегда создаётся копия для отката. После замены службы перезапускаются от учётки выше («Управление службами»).
