# UI-аудит bAWH (черновик)

> Рабочие заметки к [`UI_GUIDEBOOK.md`](UI_GUIDEBOOK.md).  
> Финальные 5 улучшений будут в PR / ответе после отчётов субагентов.

## Уже подтверждённые проблемы

### Баги / несоответствия ролям

1. **Карточка → «Командная строка» скрывает скрипты у operator**  
   `devices/_command_actions.html` гейтит UI через `is_admin`, хотя backend передаёт `scripts` через `user_can_run_scripts` и `POST /devices/<id>/scripts/run` разрешает operator для published. Сообщение «только администратору» ложное для operator. Произвольная команда (`diagnostics.command`) — действительно admin.

2. **Лишняя скобка в тексте сервиса отчётов**  
   `password_expiry/dashboard.html` и `sector_daily_report/dashboard.html`:  
   `по расписанию <code>…</code>).` — лишняя `)`.

### Дубли функций / IA

3. **Тумблер «Сервис отчётов»** — и на dashboard, и в settings обоих модулей (явный дубль; settings даже пишет «тот же тумблер»).

4. **Снимок железа** — полный блок на overview и снова на вкладке «Оборудование» (+ кнопка опроса в обоих местах у admin).

5. **«Проверить сейчас»** — AJAX на overview и form POST на вкладке «Опросы» (одна capability, два входа на одной карточке).

6. **SMTP** — живёт только в «Настройки → Пароли AD», а «Отчёт по секторам» ссылается туда же (путаница имён раздела).

7. **Параметры** — длинная страница: PsExec, WMI, ICMP-опрос, железо, службы; нет внутренней навигации по якорям (кроме `#service-control` извне).

## Кандидаты в топ-5 улучшений (предварительно)

1. Разделить на карточке: скрипты (operator+) vs произвольная команда (admin); убрать ложный copy.
2. Канонический дом тумблера расписания — только dashboard; в settings оставить cron/получателей.
3. Overview: одна строка-сводка железа + ссылка на вкладку; опрос — только на «Оборудование».
4. Вынести общие SMTP-настройки из «Пароли AD» в нейтральный «Настройки → Почта» (или «Параметры → SMTP»).
5. Объединить диагностический ICMP на карточке: один primary «Проверить» + secondary Ping(лог)/Tracert на вкладке опросов; с overview убрать дубль или оставить только быстрый check без второго primary на polls.
