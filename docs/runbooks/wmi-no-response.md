# WMI не отвечает

## Симптом

Ping до хоста есть, но серийник/MAC/текущая УЗ не обновляются; в журнале опроса растут `errors`.

## Проверка

1. Параметры → учётка WMI (discovery): задана, пароль сохранён.
2. Учётка имеет права локального админа / WMI на целевых ПК.
3. Firewall: RPC/WMI (135 + динамические порты) с сервера bAWH.
4. Время/DNS: сервер резолвит hostname устройства.
5. Ручной poll: кнопка «Запустить опрос сейчас», смотреть `errors` и текст `error`.

## Не делать

Не коммитить пароли WMI в git; не читать Fernet-секреты в логи.
